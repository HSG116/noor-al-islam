إنشاء قسم احترافي داخل موقع “نور الإسلام” لتوليد فيديوهات القرآن القصيرة (Quran Reels Studio)

أريد إنشاء قسم متكامل داخل موقع نور الإسلام وليس تطبيق منفصل. القسم يكون احترافي جداً من ناحية التصميم والأداء وسهولة الاستخدام، ويعمل باستخدام:

* React
* TypeScript
* Vite
* Node.js
* FFmpeg
* ImageMagick
* Pexels API
* Quran API
* Audio API
* Tailwind CSS
* Framer Motion
* React Query
* React Router
* React Hook Form

ويكون الكود منظم وقابل للتطوير بنسبة 100%.

⸻

الفكرة

القسم يسمح للمستخدم بإنشاء فيديوهات قصيرة (Reels / Shorts / TikTok) لآيات القرآن الكريم بجودة احترافية مع خلفيات طبيعية متحركة، وتأثيرات سينمائية، وانتقالات جميلة، وإخراج احترافي.
